# 📚 Школьный счётчик

Интерактивное веб-приложение для мотивации детей через систему поощрений и штрафов.

## ✨ Возможности

- ✅ Добавление заданий с поощрениями и штрафами
- ⏱️ Бонус за время выполнения задания
- 🔒 Ограничение заданий (1 раз в час, день, неделю)
- 📊 Визуальный таймер обратного отсчёта
- 🔊 Звуковые эффекты
- 💾 Автосохранение в localStorage
- 📱 Адаптивный дизайн для телефонов

## 🚀 Как использовать

1. Откройте `index.html` в браузере
2. Нажмите ➕ чтобы добавить задание
3. Нажимайте на кнопки чтобы зарабатывать или терять баллы
4. Баланс автоматически сохраняется

## 🛠 Технологии

- Чистый HTML/CSS/JavaScript
- Web Audio API для звуков
- LocalStorage для сохранения данных
